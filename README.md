# Accessories

ICELOLLY accessory inventory management app.

Before changing the app, read the latest `main` and `PROJECT_HANDOFF.md`.

The app's primary role is accessory inventory management. Canonical accessory stock is `accessoryStock/shared.designs`. Sales Manager remains the event sales and business operations layer, while the ICELOLLY website and WooCommerce remain the customer facing portfolio and ecommerce layer.
